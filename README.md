 Book Explorer

A responsive and interactive web app that lets you discover, search, and save your favorite books.

## Live Features
- Browse books from the Open Library API
- Search for books by title
- Add and remove favorite books
- Favorites saved with localStorage
- Fully responsive on all devices

## Built With
- HTML & Tailwind CSS
- Vanilla JavaScript
- Open Library API
- ES6 Modules

##  Project Structure
book-explorer/
├── index.html        → Homepage
├── favorites.html    → Favorites page
├── about.html        → About page
└── js/
├── app.js        → Main entry point
├── fetchBooks.js → API module
└── favorites.js  → Favorites module

##  How to Run
1. Clone the repo
2. Open `index.html` in your browser
3. Start exploring books!
