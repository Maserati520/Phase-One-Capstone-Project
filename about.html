About Book Explorer

Book Explorer is a simple and beautiful web app that lets you discover, search, and save your favorite books from the Open Library — a free and open catalog of millions of books.

What you can do:

  • Browse books from the Open Library API
  • Search for books by title
  • Save your favorite books
  • Use it on any device — fully responsive

Built with:

  • HTML & CSS
  • Tailwind CSS
  • Vanilla JavaScript
  • Open Library API
